Help Center

This page explains how to use the GLA CRM + Dashboard platform.

1. Log In

Go to /login and enter your username and password.

After logging in, you will land on the Admin Home page.

2. Upload a CSV

  1. Click Upload in the top menu.
  2. Choose the upload type.
  3. Select your CSV file.
  4. Click Upload File.

Upload types currently available:

  • VRVH voter file
  • Purge list
  • Outreach/contact history
  • Registration apps
  • Zodiac data
  • Primary election data
  • Other

Important: For now, upload CSV files only. Do not upload real voter data until the private data rules and production setup are finished.

3. View Upload History

  1. Click Uploads.
  2. Review the file name, upload type, upload date, row count, and status.

This confirms that the platform saved the file and counted the rows.

4. Inspect a Data Source

  1. Click Data Sources.
  2. Find the uploaded file.
  3. Click Inspect.

The Import Detail page shows:

  • Detected columns from the CSV
  • Non-empty and blank sample counts
  • Suggested platform field mapping
  • Available reports that can be run from that file

5. Run a Report

  1. Open a file from Data Sources.
  2. Choose a report from the dropdown.
  3. Click Run Report.

The first version creates simple grouped reports from the uploaded CSV. For example, a County Performance Report will group records by county when a county column exists.

6. Open the Dashboard

  1. Click Dashboard in the top menu.
  2. The platform opens the existing dashboard from the github-pages folder.

The next build step is connecting uploaded/imported data directly into dashboard dropdowns and dashboard metrics.

7. What Each Page Does

Page Purpose
Admin Main home page with quick links and latest uploads.
Upload Upload a CSV and choose what type of data it is.
Uploads View upload history and row counts.
Data Sources Inspect uploaded files, detected columns, and suggested mappings.
Reports Report library. Some buttons are placeholders for the next build step.
Dashboard View the existing GLA dashboard.
Help Instructions for using the platform.

8. Privacy Rules

This platform must protect private voter and contact data.

Do not publish or commit raw files, voter names, voter IDs, birth dates, addresses, phone numbers, emails, person-level outreach history, SQLite databases, or private source files to GitHub Pages.

The public dashboard should only show aggregate data.
